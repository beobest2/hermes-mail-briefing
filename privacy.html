Privacy Policy

Hermes Mail Briefing · Last updated 2026-09-30

What data is accessed

With the owner's consent, the app uses the Gmail API read-only scope (gmail.readonly) to read message metadata (subject, sender, date) and short body excerpts from the owner's own Gmail accounts. Attachments are not downloaded.

How data is used

The data is used solely to generate a private mail briefing for the owner. The app never sends, modifies, or deletes email.

Sharing

Data is not sold, shared with, or disclosed to third parties, and is not used for advertising.

Storage and retention

Only the most recent briefing snapshot is stored, on a private server controlled by the owner. It is overwritten on each collection.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
